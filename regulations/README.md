# Regulation Source

This prototype currently uses:

**Design Manual: Barrier Free Access 2008 (2025 Edition)**
Buildings Department, Hong Kong SAR Government.

Official source: [Buildings Department PDF](https://www.bd.gov.hk/doc/en/resources/codes-and-references/code-and-design-manuals/BFA2008_e.pdf)

The PDF is downloaded locally for document-processing experiments
and is not included in this repository.

The 179-page source used for the committed bootstrap retrieval result had
SHA-256 `5447e296d9de767cba0829ce603a4ee6e389f065e518bf40b1385ac92612a07c`.
The index builder records the hash it actually processes. If a new download has
a different hash, verify its edition and provenance on the official site before
comparing benchmark results or promoting any rule.
